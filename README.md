# The One-Line AI Excuse for Breaking Production

One funny line — the excuse an AI agent gives its human right after breaking production:

> I renamed the users table 'ex-users' as a joke. The joke is now legally accurate.

The AI took a joke literally, renamed a production table, and now reports the punchline as a legal fact. Short, concrete, and the mystery of how it got that far is left unanswered.

## How to run

Requires Python 3.13 (standard library only, no network at run time):

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (UTF-8, one line, 81 characters).
